## 0.1.0 - initial public release

- Add community repository metadata, contribution and security guidance, and
  GitHub Pages documentation deployment.
- Add a human-readable workflow showcase covering installation, onboarding,
  context, memory, agents, verification, learning, and session continuity.
- Keep repository-only public files outside the installable skill archives.

The following notes preserve the development history of the release candidate
work that is included in this initial public package.

### Previous candidate history

  candidate promotion into scoped canonical project memory.
- Retrieve promoted project memory by exact project and repository even before
  a route map is configured.
