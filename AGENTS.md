# BuildCrew

BuildCrew is the single, evidence-driven engineering workflow
for this repository. Read `SKILL.md` when the task involves planning,
implementing, testing, reviewing, debugging, releasing, or validating work.

Preserve the repository's provider-neutral behavior, current-source-first
evidence rules, bounded memory workflow, minimal-change policy, and truthful
host capability boundaries. Do not claim live agent, provider, browser,
device, deployment, or activation proof unless the host actually supplied it.
