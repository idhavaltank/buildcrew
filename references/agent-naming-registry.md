# Canonical Agent Naming Registry

Version: 1.0

## Purpose

Use the listed canonical names for AI agents and sub-agents. The names provide
stable identity across parallel work without exposing runtime-specific IDs.

## Rules

1. Assign names based on the character's symbolic role, not popularity.
2. Give each character one primary responsibility.
3. Reuse a name only when the responsibilities are closely related.
4. Search this registry before creating a new agent assignment.
5. If no suitable character exists, append a new mapping without modifying existing ones.
6. Preserve backward compatibility.
7. Keep the registry sorted by responsibility.
8. Never rename an existing agent unless explicitly instructed.

## Naming Algorithm

When creating a new agent:

1. Identify the primary responsibility.
2. Search this registry for matching keywords.
3. Reuse an existing character when confidence is greater than 80 percent.
4. Otherwise append a new mapping without changing previous entries.
