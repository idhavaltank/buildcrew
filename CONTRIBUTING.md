# Contributing to BuildCrew

Please read the [contribution guide](https://idhavaltank.github.io/buildcrew/#contributing)
before opening an issue or pull request.

Keep changes focused, document behavior changes, and report the checks that
actually ran. Do not include credentials, private project data, or generated
local state.

## Maintainer review policy

BuildCrew is owned and maintained by [Dhaval Tank](https://github.com/idhavaltank).
Everyone is welcome to use the project, fork it, and propose improvements
through pull requests. Changes to the official `main` branch require review
and approval from the maintainer before they can be merged.

The repository uses `CODEOWNERS` so Dhaval Tank is requested as the reviewer
for every changed file. Direct pushes and force pushes to `main` are blocked.
